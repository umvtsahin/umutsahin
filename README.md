# FitFlow

Kurulum: bu klasörün içeriğini GitHub reposuna yükle → Settings > Pages > Branch: main / root.
Telefonda: linki aç → iPhone: Safari Paylaş > Ana Ekrana Ekle | Android: Chrome ⋮ > Uygulamayı yükle.

PC'de test: klasörde `python -m http.server 8000` → http://localhost:8000 (index.html'e çift tıklamak da çalışır, sadece çevrimdışı mod/PWA olmaz).

Görseller: img/ klasörüne hareket-id.jpg (ör. img/leg-press.jpg).
Veri tarayıcıda saklanır; Yönetim > Veri > Dışa Aktar ile yedek al.
